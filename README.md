# CursoDeC-Sharp

Este repositório contém meus estudos e exercícios iniciais em **C#**, desenvolvidos durante o aprendizado da linguagem e dos principais conceitos da plataforma .NET.

## 📚 Conteúdos abordados
- Sintaxe sintria básica da linguagem C#
- Tipos de dados
- Entrada e saída de dados no console
- Variáveis e constantes
- Operadores aritméticos e lógicos
- Estrutura de um projeto Console

## 🎯 Objetivo
Consolidar a base da linguagem C#, entendendo sua sintaxe, tipagem forte e funcionamento geral, servindo como fundamento para Programação Orientada a Objetos e desenvolvimento de aplicações maiores.

## 🛠️ Tecnologias
- C#
- .NET
- Aplicação Console

## 📌 Observações
Este repositório representa o **início da jornada com C#**, focado em aprendizado e prática constante.
